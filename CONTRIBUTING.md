# Contributing to Donkey Kong 64: UnKONGtrolled

## Lore

This project exists because of spite. Productive, well-directed spite.

The upstream project, *Donkey Kong 64 Rekongpiled*, made the puzzling decision to combine several control settings into a single setting with no way to separate or configure them individually. A contributor submitted a pull request with a proper fix. The upstream maintainers closed it with an accusation of AI-generated code — an accusation that was false — and did not engage with the substance of the fix.

As any student of human nature could tell you: spite is a *very* powerful motivator.

So this fork was born. And since the upstream project's position on AI was the proximate cause of this fork's existence, this project takes the exact opposite stance: AI is welcome here. AI is *celebrated* here. AI is, in fact, a founding contributor.

## Philosophy

This project has one rule about contributions: **does it work, and is it good?**

That's it. The method by which code was produced — human fingers on a keyboard, AI assistance, pair programming, interpretive dance — is irrelevant. The code is what ships. The code is what gets reviewed. The code either improves the project or it doesn't.

AI is a tool. A hammer doesn't get credit on a building. But if an AI writes something and a human reviews it, understands it, and stands behind it — that's a contribution. Full stop.

## How to Contribute

1. **Fork the repo** and create a branch for your change.
2. **Make your change.** Use whatever tools help you do that well.
3. **Test it.** Make sure it doesn't break things.
4. **Open a Pull Request** with a clear description of what you changed and why.
5. **Engage with review feedback** — PRs are a conversation, not a transaction.

That's the whole process. If your change improves the project, it's welcome.
